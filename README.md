> **Meet Pythagoreous:**
> The ancient philosopher and mathematician, reborn as a multi-modal AI dashboard. Converse with timeless wisdom, explore modular algebraic pipelines, and experience the future of chat automation.

---

## 🚀 Features

- **Multi-Chat Flet Dashboard**: Run unlimited concurrent chats, each with its own persona, model, and system instructions.
- **Voice & Text Input**: Speak or type—Pythagoreous listens and responds in real time.
- **Self-Healing AI**: Automatic code correction via Llama API. Never get stuck—just ask for a fix!
- **Snapshot & Trace**: Every chat, every response, every pipeline step is logged and reproducible.
- **Modular APT Pipelines**: Explicit algebraic equations, indexed modules, and full traceability.
- **Modern UI**: Beautiful, responsive, and industry-standard. Built with Flet and Python 3.12+.
- **Netlify Llama Proxy Integration**: Universal API access for all Llama endpoints. Drag-and-drop compatible.
- **Export & Archive**: Save chats, snapshots, and results for research or compliance.
